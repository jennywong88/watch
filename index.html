⌚ 手錶庫存管理

手錶 · 部件 · 全局聯動扣減 · 低庫存警報

⌚ 手錶
每款手錶可配置殼、面、針、底蓋、錶帶、機芯、錶圈、日曆盤等部件。部件是全局共享的：同一部件被多款手錶使用時，扣減自動聯動。任一部件無貨即整錶缺貨。
🧩 部件庫存 0
部件為全局唯一庫存，多款手錶可共用。庫存低於該部件閾值（預設 5）時自動標紅警報；可登記「訂購中」及預計到貨日期。負數＝欠貨（預售已接單、待配件到貨補上），會正常保留與顯示。
類型部件名稱庫存訂購預計到貨警報閾值使用於操作
🧾 銷售記錄 累計售出 0 隻
登記銷售後自動扣除該款手錶所用部件的全局庫存；其他共用同一部件的手錶同步生效。可隨時撤銷銷售、按明細加回庫存。
📊 時段銷售排名
統計任意時段（例如某個月）各款式售出數量，由高到低排名；日期含首尾當天。
～ 共 —
選擇時段後顯示排名。
🤝 客戶預留
客戶預留手錶時建立預留單：會立即暫時扣除相應部件的庫存並標註客戶名稱；客戶下單後，一鍵「轉為銷售」即可自動把預留的數量變成銷售記錄（不重複扣庫存）。
💭 缺貨客問「想要」
把缺貨手錶被客人詢問「想要」的日期與數量記錄下來，作為未來訂貨／補貨的參考（不影響庫存與銷售數字）。預設依「同款被問的次數」排名，被問最多的款式排最前；點「明細」可展開該款的逐筆詢問。缺貨手錶卡片上也有「＋ 想要」快捷按鈕。
📅 產品時間表
為每款手錶安排上架日期與具體時間，並記錄「動作」（可自由填寫或選用模板）；庫存數量與「部件庫存」即時聯動（可組裝數＝各部件類型可用數的最小值）。
📌 重要日程
記錄會議、活動等重要日程並提醒：日期／時間／和誰／備忘；今天高亮、逾期標紅；可點「✓ 完成」，完成的日程會自動折疊收合。
📋 訂單記錄
記錄客戶名、訂單號、數量、付款（支援分兩次或三次收款）、寄出時間與快遞單號。
📦 暫時 Hold 住
部分貨品已寄出、剩餘稍後單獨寄出；預計寄出日期接近（3 天內）或逾期會自動標紅；完成寄出（填了「實際寄出」日期）的項目會自動折疊收合。
🧾 訂單生成
依 WMT0944 版型快速生成訂單：點選手錶、數量自動帶出圖片與規格；可輸出 .xlsx（Excel）或 .pdf（列印另存）。
✏️ 訂單編輯器
頁頭與檔名同步為 WMT[四位編號]_[年份]；數量>1 的 QTY 儲存格自動黃底高亮。
WMT _
🖨️ 訂單預覽（與輸出／列印一致）
匯出 PDF 時使用瀏覽器「另存為 PDF」；頁頭與檔名同步為訂單編號。
💬 客戶回答模板
維護客戶常問問題與標準回答；回答支援粗體／斜體／紅色字等格式，一鍵複製後貼到 Gmail 保留格式。
🧭 快速定位
一鍵跳到以下欄目（自動掃描本頁所有欄目，新增即自動出現）。
🗒️ 便籤
記錄重要但零碎的筆記；輸入即自動保存（約 1 秒後寫入本地備份）。在便籤上按右鍵（Mac 觸控板雙指點按／手機長按）即可叫出操作選單（發佈、顏色、排序、刪除）；顏色圈圈可自由命名當作標籤。
📌 其他事件
記錄維修、糾紛等不常用但重要的事件；可標註「重要」自動置頂；狀態可逐條記錄「日期＋做了什麼」，備註可填寄回訂單號並附圖片；結束日期已到的「已結束」事件會自動折疊收合，需要時再展開查看。
💰 客製化價格表
記錄某個部件進行某種動作（如 aged）的加價金額（USD），可快速檢索。

💾 自動備份
資料即時保存在本瀏覽器（localStorage）。設定一次備份資料夾後，任何資料變動都會自動寫入該資料夾的 watch-inventory-backup.json——建議選擇本網頁所在的資料夾，即可實現「網頁與備份同資料夾」。

☁️ 雲端同步（GitHub Gist）
讓 Mac 與 iPad 共用同一份資料：開啟網頁時自動下載雲端最新資料，任何修改約 2.5 秒後自動上傳到你的 secret gist。token 只存在這台裝置的瀏覽器，不會寫進備份檔。
尚未設定雲端同步。
ⓘ 產生 token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 只給 Gists: Read and write（其他權限都不用給）→ 複製貼到上面。
ⓘ 資料 Gist 建議用 secret gist（不被搜尋，但知道 ID 的人可讀）。可按「🧩 自動建立資料 Gist」一鍵產生。
ⓘ token 只存在這台裝置的瀏覽器，不會寫入備份檔，也只會送到 api.github.com；換裝置（例如 iPad）要各輸入一次。

🔒 進入密碼
為整個網頁設定進入密碼：設定後，關閉頁面再開啟（或新開一個分頁）都必須輸入密碼才能進入；同一工作階段內（頁面未關閉）不需重複輸入。修改或移除密碼時須先驗證目前密碼。

ⓘ 密碼僅保存在本瀏覽器（localStorage），不會寫入備份檔，還原備份不會影響密碼。
ⓘ 若忘記密碼：清除此網站的瀏覽器資料，或手動刪除 localStorage 中的 wi_pw_salt／wi_pw_hash／wi_pw_algo 即可重設。
